# Buffera 0.3.0

Для Mac с Apple Silicon и macOS 14 или новее. Сборка 3.

## Что нового

- Проверка обновлений: тихая точка на значке в строке меню и раздел «Настройки → Обновления». Фоновая проверка выполняется не чаще раза в сутки; можно проверить вручную, пропустить версию или отключить автоматическую проверку. Установка остаётся ручной.
- История открывается сразу. В настройках можно выбрать, через какое время после закрытия сбрасывать поиск, фильтры и выделение; по умолчанию — через одну минуту. Открытое окно не сбрасывается по таймеру.
- Миниатюры сохраняются в собственном кэше Buffera. Открытие истории больше не читает оригиналы файлов из «Документов» и других папок. Если миниатюры нет, карточка показывает значок и имя файла; явный просмотр через Пробел или ⌘Y может запросить доступ к оригиналу и сохранить миниатюру.
- Исправлена загрузка переводов в установленном приложении: ресурсы читаются внутри `.app`, без обращения к папке исходного проекта, которое могло вызвать запрос доступа к «Документам» при запуске.

Кэш миниатюр ограничен 64 МБ и 512 файлами. Скрытые записи не кэшируются; скрытие и удаление записи очищают её миниатюры. Проверка обновлений читает публичные сведения GitHub Releases и не отправляет историю буфера обмена.

## Установка и обновление

Скачайте `Buffera-macOS-arm64.dmg`, завершите Buffera и перетащите приложение в «Программы», подтвердив замену. Если приложение установлено в другой папке, замените его там. История, настройки и скачанные модели хранятся отдельно. После обновления перезапустите подключённый MCP-процесс.

В версии 0.2.0 встроенной проверки обновлений ещё нет: переход на 0.3.0 выполняется ручной загрузкой DMG. Следующие выпуски можно будет находить через настройки приложения.

Сборка подписана ad-hoc, без Developer ID и нотарификации Apple. Если macOS блокирует запуск, после первой попытки откройте «Системные настройки → Конфиденциальность и безопасность» и разрешите запуск. Связка ключей может повторно запросить доступ при работе со скрытыми записями.

Веса локальных моделей скачиваются отдельно в настройках. SHA-256 установочного файла указан в `SHA256SUMS.txt`.

## English

- Added daily background update checks, a quiet menu-bar dot, and update settings with manual checks and version skipping. Installation remains manual.
- History opens immediately. Configure when search, filters and selection reset after closing the panel; the default is one minute. An open panel does not expire.
- Thumbnails use Buffera's own cache. Opening history does not read original files. File-only clips without a cached thumbnail show an icon and filename; an explicit preview may request folder access and cache the thumbnail.
- Fixed packaged localization so the installed app loads translations from its own bundle instead of accessing the source project in Documents.

Download the DMG, quit Buffera and replace the installed app. History, settings and downloaded models are kept separately. Restart connected MCP processes. Updating from 0.2.0 requires a manual download because that version has no update checker.

Requires Apple Silicon and macOS 14+. This build is ad-hoc signed and is not notarized. Model weights are downloaded separately; the DMG checksum is included in `SHA256SUMS.txt`.
