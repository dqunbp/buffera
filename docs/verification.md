# Проверка первой сборки, 16 октября 2026

- Release-сборка на Apple Silicon с установленными Command Line Tools: успешно.
- 9/9 исполняемых проверок SQLite: сохранение форматов после открытия базы, дедупликация, даты/тип/слова, буквальные SQL-символы, лимиты, каскадное удаление, пагинация, границы хеша, отказ от пустого payload.
- Smoke-проверка готового бинарника на отдельном системном pasteboard: несколько элементов и форматов, отсутствие собственного повторного захвата, внешний захват, TIFF → PNG, маркер конфиденциальности — успешно.
- Нативное окно осмотрено через UI automation. Проверены захват двух текстовых фрагментов, поиск, просмотр, стрелки, Enter с последующей вставкой выбранного текста, переходы ⌘⌥V/C внутри открытого окна, отображение произвольного периода, сохранение записей после перезапуска.
- До изменения поведения отпускания клавиш пользователь подтвердил глобальный вызов из другого приложения обычной клавиатурой. Диагностика в 21:22 (локальное время Mac) зафиксировала успешные регистрации (`status=0`), открытие панели, несколько нажатий V, два нажатия C и закрытие с возвратом фокуса.
- По следующему запросу пользователя автоподтверждение при отпускании модификаторов полностью удалено. Новая release-сборка установлена и запущена; в окне проверены поиск и оба направления ⌘⌥V/C: после отпускания сочетаний окно и запрос остаются, выбранная строка меняется. Теперь подтверждение выполняется только Enter или двойным щелчком.
- Пользователь подтвердил видимость нового значка Bufera в верхней системной строке меню. Pasta завершена перед проверкой.
- Экспорт через системный NSSavePanel/Finder и специфические форматы сторонних редакторов ещё не прошли полный ручной сценарий; преобразование изображения и сохранение бинарных форматов покрыты smoke-проверкой.

В истории приложения остались два явно тестовых текстовых фрагмента. OCR, поиск с опечатками, эмбеддинги и LLM не входят в эту версию.

## Одноколоночное окно и сохранение геометрии

- Release-сборка и строгая проверка подписи установленной копии проходят. Smoke-проверка именованного pasteboard проходит; пользовательский буфер для неё не используется.
- В приложении проверены список без правой панели, поиск тестовых записей и миниатюра изображения. При выборе картинки появляются обе кнопки экспорта.
- Через UI automation окно уменьшено с 671 × 673 до 481 × 403 pt. Поиск, список, подсказки, кнопки изображения и произвольный период помещаются; список прокручивается.
- Размеры 671 × 673 и затем 481 × 403 восстановлены после перезапусков. Native defaults содержат `NSWindow Frame BuferaHistory` с рамкой окна; повторное открытие больше не центрирует её. После последнего перезапуска проверен переход ⌘⌥V к следующей тестовой записи.
- Перетаскивание заголовка не удалось надёжно воспроизвести через UI automation. Сохранение перемещения обрабатывает `windowDidMove`; перетаскивание фона разрешено. Физическое перетаскивание и отключение второго монитора остаются ручными сценариями проверки.
- Для фона используется системный `.popover / .behindWindow`. Захват отдельного окна не показывает композицию с рабочим столом; степень визуального размытия проверяется на экране пользователя.

## Фокус, фильтры, скрытые записи и временные картинки

- Core-проверки: 19/19, включая миграцию реальной схемы 1 в 2, отказ от неизвестной будущей версии, фильтр приложения вместе с текстом/типом/датой, маскировку метаданных, отсутствие скрытого текста в поиске, сохранность исходного payload, ручное скрытие и дедупликацию.
- Smoke-проверка release-бинарника на отдельном именованном pasteboard проходит: современные и старые маркеры конфиденциальности, смешанные группы, сочетание конфиденциальности с transient, пропуск обычного transient, восстановление исходных форматов, явный показ RTF-текста и источник из метаданных. Пользовательский буфер этот тест не использует.
- Отдельные проверки `TemporaryImageExports` проходят: повторное использование имени, срок хранения, лимит объёма, права доступа и изоляция очистки от посторонних файлов и ссылок.
- Перед миграцией пользовательской базы создана резервная копия `Backups/history-before-v2.sqlite`. После обновления база сообщает версию 2, сохраняет 10 записей и проходит `PRAGMA quick_check`.
- После замечания пользователя о фокусе убран режим `.nonactivatingPanel`; глобальное открытие теперь активирует Bufera и устанавливает поиск первым responder. В установленной сборке ввод поиска работает без предварительного щелчка по полю.
- В окончательной сборке через UI выбрана тестовая запись и нажат Enter. В журнале 22:16:06 зафиксированы `Confirm requested`, `Confirm completed`, `Panel closed: restoreFocus=true`; окно исчезло из списка открытых приложений. Чтение AX-состояния самой Bufera после закрытия намеренно не использовалось: инструмент может повторно открывать приложение.
- Меню типа/источника и календарь учитываются как отдельное взаимодействие: основная история не перехватывает их Enter/стрелки. В UI запрос «проверк» дал две тестовые записи, выбор приложения Bufera оставил одну и выделил активный фильтр.
- Календарный поповер визуально проверен: быстрые периоды и два календаря на русском помещаются. Выбор «Сегодня» закрывает поповер и оставляет основное окно открытым с активным фильтром.
- Кнопка «Показать в Finder» открыла `ImageExports` с выбранной PNG-копией. Файл находится в системной временной папке `local.bufera.app/ImageExports`, имеет права 0600. Постоянное сохранение через NSSavePanel остаётся отдельным ручным сценарием.
- Маскированные строки в установленном приложении отображаются точками и значком замка без текстовой подсказки. Содержимое пользовательских скрытых записей при проверке не раскрывалось; явное раскрытие и сохранность оригинала проверены на синтетических данных.
- Окончательная release-сборка установлена в `~/Applications/Bufera.app`, строгая проверка подписи проходит. Изменения пока не закоммичены.
