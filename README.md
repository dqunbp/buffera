# Buffera

Название отсылает к английскому `buffer` и русскому «буфера». Фирменный знак — пара округлых контуров: монохромный в строке меню, сиреневый на иконке приложения и в настройках. Пакет, исполняемый файл и модули называются Buffera, системный идентификатор — `local.buffera.app`.

Локальный менеджер истории буфера для macOS 14+, первая версия. Swift + AppKit, системная SQLite и локальное распознавание текста через Apple Vision, без внешних зависимостей. LLM пока не включена.

## Сборка и запуск

Нужны Command Line Tools со Swift 5.9 или новее. Полный Xcode не обязателен.

```sh
zsh scripts/build-app.sh
open dist/Buffera.app
```

В среде, где запрещён вложенный `sandbox-exec`, передайте `--disable-sandbox` скрипту сборки. Это отключает только песочницу манифеста SwiftPM, а не защиту macOS приложения.

Получается локально подписанный ad-hoc пакет `dist/Buffera.app`. Для распространения понадобится Developer ID и notarization. Можно скопировать пакет в Applications. Для автозапуска добавьте его в «Системные настройки → Основные → Объекты входа».

Если Documents обслуживается файловым провайдером, тот может повторно добавить FinderInfo к собранному `.app`, нарушив строгую проверку подписи. Запускайте рабочую копию вне синхронизируемой папки, например из `~/Applications/Buffera.app`. Копирование без служебных атрибутов: `ditto --norsrc --noextattr dist/Buffera.app ~/Applications/Buffera.app`, затем `codesign --force --sign - ~/Applications/Buffera.app`.

Перед запуском закройте Pasta, если она занимает `⌘⌥V`. Buffera не вставляет автоматически и не запрашивает Accessibility для синтетического нажатия клавиш. macOS может отдельно запросить доступ к буферу обмена: для фоновой истории его нужно разрешить.

## Управление

| Действие | Клавиши |
| --- | --- |
| Открыть историю / следующий элемент | `⌘⌥V` |
| Предыдущий элемент, пока окно открыто | `⌘⌥C` |
| Перемещаться между строками списка или сетки | `↑` / `↓` |
| Перемещаться между соседними карточками вне поля поиска | `←` / `→` |
| Поместить выбранное в буфер и закрыть окно | `Enter` или двойной щелчок |
| Сразу выбрать одну из первых девяти записей текущего списка | `⌘1`–`⌘9` |
| Открыть просмотр выбранной записи | `Пробел` при фокусе в списке; `⌘Y` также из поиска |
| Добавить в избранное / убрать из него | `⌘D` |
| Показать записи рядом по времени копирования | `⇧⌘N` |
| Скрыть содержимое / временно показать скрытое | `⇧⌘H` |
| Показать картинку в Finder | `⇧⌘R` |
| Сохранить картинку в выбранную папку | `⇧⌘S` |
| Перейти к поиску | `⌘F` |
| Переключить фокус между поиском и карточками | `Tab` |
| Показать / скрыть боковое меню фильтров | `⌘⌥S` |
| Открыть настройки внешнего вида | `⌘,` |
| Очистить запрос и фильтры, вернуться ко всей истории | `⌘0` |
| Отменить без изменения буфера | `Esc` |
| Удалить выбранную запись | `⌘⌫` |

Одиночное нажатие `⌘⌥V` активирует Buffera и открывает окно с фокусом в карточках. Если сразу отпустить клавиши, окно остаётся в обычном режиме: дальнейшие `⌘⌥V/C` только двигают выбор и больше не включают автозакрытие до следующего открытия. Для быстрого выбора нужно непрерывно удерживать `⌘⌥` с самого открытия и ещё раз нажать V или C: V выбирает следующую запись, C — предыдущую. Отпускание `⌘` или `⌥` после такого перебора помещает выбранную запись в буфер и закрывает окно. Открытие через меню или значок приложения также оставляет окно в обычном режиме; автоматический повтор от удержания самой V не включает перебор. В сетке `↑/↓` переходят на строку вверх или вниз, `←/→` — к соседней карточке. Enter, кнопка «В буфер» в карточке или двойной щелчок фиксируют запись, помещают её содержимое в системный буфер и закрывают окно, возвращая фокус предыдущему приложению. Вставка выполняется пользователем в целевом приложении (обычно `⌘V`; Buffera не меняет пользовательские переназначения). В обычном списке Escape или переход в другое приложение закрывают окно без подтверждения; Escape также отменяет ещё не завершённое подтверждение. В просмотре и режиме соседей Escape сначала возвращает на предыдущий уровень.

После успешного выбора запись поднимается наверх без дубликата; дата копирования, приложение, избранное и маска сохраняются. В обычной истории при следующем открытии выбрана эта запись. Esc и переход в другое приложение сохраняют выделение без копирования и перестановки. Новое внешнее копирование (в том числе повторное) становится первым и выделенным, если подходит под текущие фильтры; иначе выделение в отфильтрованном списке сохраняется.

Начните печатать при фокусе в списке, чтобы начать новый поиск. `⌘F` переводит фокус в существующий запрос для редактирования; пробелы в поле поиска остаются обычными пробелами. Запрос, фильтры и раздел «История»/«Избранное» сохраняются между закрытиями окна, пока Buffera работает. После перезапуска приложения они сбрасываются. Вернуться ко всей истории можно кнопкой сброса рядом с поиском или `⌘0`.

Через маленький значок планшета с зажимом справа в верхней системной строке меню тоже можно открыть историю. В его меню виден статус `⌘⌥V`; при конфликте доступно повторное подключение сочетания. Обычное копирование `⌘C` остаётся доступно в поле поиска.

Карточки расположены списком или сеткой; боковое меню с типами, периодом и приложениями можно скрыть кнопкой слева от поиска или `⌘⌥S`. Активные фильтры при этом сохраняются, а тип, дата и приложение доступны через значок фильтров рядом с поиском. В каждой карточке находятся содержимое, приложение, дата и действия: избранное, просмотр, копирование и доступные для её типа скрытие или экспорт. Кнопки видны постоянно, без наведения. Названия действий и сочетания клавиш видны в подсказках; контекстное меню содержит те же действия и удаление. Удержание `⌘` показывает номера первых девяти записей для быстрого выбора. Выбранная карточка выделена обводкой. Звезда обновляет карточку на месте; снятие звезды в избранном убирает только эту запись.

Тип «С устройств» показывает новые записи с маркером Universal Clipboard; в карточках они подписаны «С другого устройства». Имя устройства и приложение на нём неизвестны, приложение Mac им не присваивается. «Скрытые» показывает автоматически помеченные и вручную скрытые записи. «С устройств» и «Скрытые» находятся в общем выборе типа вместе с текстом, ссылками, картинками, файлами и данными. Одновременно выбран один тип; он сочетается с поиском, датой, приложением и избранным. Старые записи не помечаются как удалённые задним числом: раньше этот признак не сохранялся.

Просмотр по пробелу или кнопке в карточке открывается временно рядом со списком. В нём можно прочитать длинный текст, рассмотреть картинку, увидеть пути файлов или перечень других форматов. Пробел и Escape закрывают просмотр, Enter выбирает запись, стрелки возвращают к списку и меняют выбор. Полный текст не показывается при случайном наведении. Скрытую запись сначала нужно явно раскрыть кнопкой «Показать содержимое».

«Скопировать иначе» — подменю по правому клику на карточке. Кнопка в карточке и `⇧⌘C` открывают тот же список. Выбор действия сразу копирует результат и закрывает историю. Дополнительного окна и подтверждения нет; `Esc` закрывает меню без копирования.

Показываются только подходящие варианты: «Без форматирования» для читаемого текста, «Форматировать JSON» для корректного JSON, который требует форматирования, «Убрать переносы строк» для соседних непустых строк, «Убрать повторяющиеся строки» при наличии повторов и «Убрать метки из ссылки» для ссылки с удаляемыми метками. Для картинки доступен «Текст с картинки» через существующий OCR; если готовое распознавание уже показало отсутствие текста, пункт скрыт. Открытие меню само не запускает распознавание. Действия недоступны для скрытых записей.

Список проверяется по полному содержимому в фоне; при первом открытии может кратко появиться «Проверяем варианты…». Каждый вариант применяется к исходному содержимому. Копируется полный результат как обычный текст; исходные форматы, дата копирования, источник, избранное и маска записи сохраняются. Как при обычном копировании, запись поднимается наверх, без создания дубликата.

Форматирование JSON меняет только пробелы и отступы: большие числа, повторяющиеся ключи и экранирование сохраняются. Очистка переносов оставляет абзацы, удаление повторов сохраняет порядок первых строк и пустые строки. Очистка одной HTTP(S)-ссылки удаляет `utm_*`, `fbclid`, `gclid`, `dclid`, `msclkid`, `yclid`, `mc_cid`, `mc_eid`, `gbraid`, `wbraid`; остальные параметры и фрагмент остаются прежними. Ссылка с распознанной подписью не изменяется, если удаление меток может её нарушить.

При ошибке история остаётся открытой, а буфер не меняется. Пока идёт обработка, `Esc` отменяет ожидающее копирование. Для обработки текста действует предел 2 МиБ на вход и результат и 128 уровней JSON; «Без форматирования» читает полный текст без этого ограничения. OCR с достигнутым пределом 200 000 символов не выдаётся за полный результат. Модели и сеть для этих действий не нужны.

«Показать рядом» открывается кнопкой часов в карточке, через её контекстное меню или `⇧⌘N`. Видны опорная запись и до 10 ближайших копирований до и после неё, от новых к старым. Соседи берутся из всей истории: запрос, тип, период, приложение и раздел избранного временно не ограничивают список. Скрытые записи остаются под маской. При открытии опора располагается по центру видимой области, насколько позволяют границы списка. Она отмечена цветной точкой и обводкой даже после перехода на соседнюю карточку; повторите действие у другой записи, чтобы пройти дальше по истории.

«Назад в историю» или `Esc` возвращает исходные запрос, фильтры, выделение и прокрутку. Если открыт просмотр, первый `Esc` закрывает его, следующий возвращает результаты. Новые копирования не переставляют соседей во время просмотра; при возвращении результаты обновляются при необходимости. Закрытие окна завершает временный режим, а при следующем открытии восстанавливается исходный поиск. Порядок соседей определяется последним внешним копированием, а не выбором записи в Buffera. Повторное копирование одинакового содержимого заменяет прежнюю дату и источник: полного журнала повторов пока нет. Функция работает и на старой истории, без моделей и миграции базы.

Шестерёнка справа от поиска, `⌘,` и пункт «Настройки…» в системном меню открывают отдельное окно настроек. Вкладки «Вид», «История» и «Клавиши» объединяют компоновку, лимиты хранения и подсказки сочетаний. Повторное открытие поднимает то же окно; его закрытие не завершает приложение. Изменения применяются сразу и сохраняются после перезапуска. Доступны обычное окно и панели у левого или правого края экрана. Обычное окно можно перемещать за свободную область и растягивать за края; его положение и размер сохраняются отдельно от ширины боковой панели. Панель занимает доступную высоту экрана, допускает изменение ширины и выезжает из выбранного края при открытии. При включённом системном «Уменьшить движение» анимация отключена. Стандартные кнопки закрытия, сворачивания и разворачивания скрыты; окно закрывается через Escape или выбор записи.

Можно выбрать 1–4 колонки и плотность в 3–12 видимых строк. Одна колонка даёт список, несколько — сетку. В обычном окне карточки имеют одинаковую высоту, минимум 96 точек. В боковых панелях высота зависит от содержимого: короткий текст занимает от 74 точек, длинный растёт до высоты, заданной плотностью. У картинок остаётся место под миниатюру и действия, а карточки одной строки сетки выравниваются по самой высокой. Минимальная ширина карточки — 230 точек, поэтому в узком окне колонок может быть меньше. Размер окна ограничивается видимой областью экрана; при отключении монитора обычное окно возвращается на доступный экран. Фон использует системную полупрозрачность с размытием, а текст остаётся непрозрачным. Вид эффекта зависит от темы и системной настройки «Уменьшить прозрачность».

## Что входит

- Захват новых копирований каждые 400 мс, пока приложение запущено и сеанс Mac доступен. При блокировке, смене пользователя или сне захват приостанавливается; накопленное за это время пропускается при возвращении, ручная пауза остаётся в силе.
- Сохранение доступных бинарных представлений каждого элемента, включая текст, RTF, PNG/TIFF, ссылки, группы файлов и пользовательские форматы.
- Повторное копирование одинакового содержимого поднимает существующую запись наверх; дата и приложение заменяются данными последнего копирования. Маска и отметка избранного сохраняются.
- Поиск по всем словам запроса без учёта регистра, по фрагментам текста, распознанному тексту картинок, имени файла и названию приложения. Символы `%` и `_` ищутся буквально. Опечатки и смысловой поиск пока не поддерживаются.
- Боковое меню с типами, периодом и приложениями. Компактное меню фильтров рядом с поиском доступно и при скрытом сайдбаре; «Сбросить фильтры» очищает их вместе, сохраняя поисковый запрос.
- В календарном поповере доступны «Всё время», «Сегодня», «Вчера», «7 дней», «30 дней» и два календаря для границ периода. Последний выбранный день включается целиком; обратный порядок дат исправляется автоматически. Периоды в 7 и 30 дней включают сегодня, даты используют локальный часовой пояс macOS.
- Фильтр приложения выбирает точное имя источника последнего копирования из имеющейся истории и сочетается с текстом, типом и датой. Имена отсортированы без учёта регистра; сама Buffera не предлагается в списке источников, но её записи остаются в общей истории. Источник определяется по метаданным буфера, когда они доступны; иначе используется активное приложение.
- Звезда в карточке добавляет запись в избранное. Раздел «Избранное» сочетается с поиском и всеми фильтрами; записи сохраняются после перезапуска и защищены от автоматической очистки истории.
- Страницы по 150 записей, подгружаемые при прокрутке. Полные двоичные данные читаются отдельно от списка.
- PNG/TIFF можно экспортировать в PNG: «Сохранить как…» создаёт постоянный файл в выбранном месте, «Показать в Finder» — временный файл с автоматической очисткой.
- Помеченные конфиденциальные записи сохраняются под точками; обычный текст или ссылку можно скрыть вручную. «Показать» временно раскрывает содержимое выбранной скрытой записи.
- Пауза записи, удаление отдельных записей, лимиты количества и объёма в меню.

## Поиск по тексту на картинках

Новые и уже сохранённые записи-картинки PNG/TIFF распознаются в фоне последовательно, по одной картинке за раз. [Apple Vision работает на устройстве](https://developer.apple.com/documentation/vision/recognizing-text-in-images), без отправки изображений в сеть. Используется точный режим с автоопределением языка; русский и английский выбираются из языков, доступных в установленной macOS. Их поддержка зависит от версии системы.

Распознанный текст дополняет обычный поиск и хранится отдельно, до 200 000 символов на запись. Исходная картинка и её форматы сохраняются: выбор найденной записи по-прежнему копирует картинку. Изображение уменьшается до 4096 пикселей по длинной стороне с учётом поворота. Обрабатывается первый кадр или страница каждого элемента буфера; PNG и TIFF одного элемента не дублируются. Ссылки на файлы не открываются, содержимое файлов на диске не распознаётся.

Картинка без текста считается обработанной. Ошибка не мешает остальной очереди: повторить неудачные попытки можно через «Повторить распознавание» в меню значка Buffera; они также повторяются при следующем запуске. Там же виден прогресс. Скрытые записи не распознаются и не участвуют в поиске по OCR; при скрытии уже обработанной записи её распознанный текст удаляется из индекса.

## Данные и ограничения первой версии

При первом запуске после переименования приложение переносит прежний каталог истории целиком, включая SQLite WAL, резервные копии и сохранённые экспорты, и копирует настройки в новый системный домен. Перенос выполняется только после закрытия предыдущей версии. Существующие новые настройки имеют приоритет; при конфликте двух каталогов приложение показывает ошибку, ничего не объединяя и не перезаписывая. Старые настройки остаются для восстановления.

История находится в `~/Library/Application Support/Buffera/`: `history.sqlite` и служебные файлы SQLite. Текущая версия схемы — 6. Базы версий 0–5 обновляются автоматически в одной транзакции: добавляются недостающие признаки скрытой записи, избранного, удалённого происхождения, отдельная таблица OCR и порядок последнего использования. Он первоначально совпадает с датой копирования, поэтому миграция не переставляет записи. Обычные картинки из старой истории ставятся в очередь распознавания; существующие идентификаторы, записи и исходное содержимое сохраняются. Неизвестная более новая версия не понижается.

Тип «Данные» объединяет форматы, для которых пока нет отдельного распознавания: внутренние объекты приложений, а также некоторые стандартные представления без поддерживаемого текстового или графического варианта. Исходные доступные форматы сохраняются для обратной вставки; пробел показывает их перечень.

«Показать в Finder» создаёт PNG в системной временной папке `$TMPDIR/local.buffera.app/ImageExports/`. Повторный показ той же картинки обновляет временный файл и срок хранения. Файлы старше 24 часов с последнего показа удаляются при запуске, раз в час, пока Buffera работает, и при новом экспорте. При превышении 256 МиБ удаляются самые старые файлы; текущий экспорт сохраняется. macOS также может очистить временную папку. Временные экспорты прежней установки продолжают очищаться по тем же правилам.

Для постоянного файла используйте «Сохранить как…» или скопируйте временную картинку в свою папку: независимую копию очистка Buffera не затронет. Исходная картинка остаётся в истории в пределах её лимитов. Папка `~/Library/Application Support/Buffera/Exports/`, созданная прежней версией и перенесённая вместе с историей, автоматически не очищается.

Лимиты меняются в «Настройки → История». По умолчанию сохраняется до 50 000 обычных записей и 5 ГБ их сериализованного содержимого. Оба ограничения применяются в транзакции после нового копирования; удаляются записи из конца обычной истории по времени последнего копирования или выбора. Избранные записи не расходуют эти лимиты и не удаляются автоматически, поэтому суммарный объём истории может превышать установленный лимит. Снятие звезды само по себе ничего не удаляет: запись снова участвует в очистке при следующем копировании. Явное удаление записи работает и для избранного. Размер самого файла SQLite может оставаться больше после удаления записей: свободные страницы переиспользуются. Экспортированные картинки в лимит истории не входят: временные файлы имеют отдельные ограничения, постоянные сохраняются до удаления пользователем.

Одна запись ограничена 64 МБ исходных представлений, индексируемый текст — 200 000 символов. Содержимое при этом сохраняется полностью в пределах 64 МБ. О пропусках или ошибках можно узнать через «Последняя ошибка…» в меню. Буфер, существовавший до запуска, не импортируется автоматически.

По выбранному режиму данные с маркерами `org.nspasteboard.ConcealedType` и старым маркером 1Password `com.agilebits.onepassword` сохраняются как скрытые записи. Список показывает точки и значок замка. Секрет не попадает в заголовок, текстовый индекс или всплывающую подсказку; запись можно найти по безопасному названию «Скрытая запись», приложению и дате. «Показать» раскрывает до 4000 символов выбранной записи только до смены выбора, обновления списка или закрытия окна. Эта кнопка не снимает сохранённую маску.

Если приложение не пометило пароль, он сохраняется как обычный текст. Такую текстовую запись или ссылку можно выбрать и нажать «Скрыть»: содержимое исчезнет из списка и текстового поиска, но останется доступным для вставки. Повторное копирование того же полного payload не снимает маску. Автоматическое определение любых паролей по самому тексту не выполняется.

Маскировка управляет показом и поиском: оригинальный payload сохраняется полностью и не шифруется отдельно от диска. Записи с `TransientType` или `AutoGeneratedType` пропускаются, если у них нет конфиденциального маркера; при сочетании маркеров сохраняется скрытая запись.

Файлы сохраняются как ссылки на оригиналы, а не резервные копии. Удалённый или перемещённый оригинал не восстанавливается. Отложенные file promises и данные, которые приложение-источник не отдаёт, пока не материализуются в самостоятельные файлы. В этом случае запись может быть пропущена с сообщением. Не все специфические форматы приложений проверены.

## Проверка

```sh
CLANG_MODULE_CACHE_PATH="$PWD/.build/ModuleCache" \
SWIFTPM_MODULECACHE_OVERRIDE="$PWD/.build/ModuleCache" \
swift run --cache-path "$PWD/.build/cache" BufferaChecks
swift build --product Buffera
.build/debug/Buffera --smoke-test
.build/debug/Buffera --ocr-smoke-test
```

Smoke-проверка использует отдельный именованный системный буфер и не меняет основной буфер пользователя. `--ocr-smoke-test` проверяет настоящий Vision на искусственных изображениях, поиск в отдельной временной базе и фоновую очередь; пользовательская история и буфер не читаются. Ограниченная среда запуска может блокировать Vision: OCR-проверку нужно запускать в обычном пользовательском окружении. Проверки не требуют XCTest или полного Xcode.

Ручная проверка: скопировать текст/картинку/несколько файлов, вызвать окно, отпустить клавиши (окно должно остаться), перебрать стрелками, нажать Enter (окно должно закрыться), затем вставить в исходное приложение. Повторно открыть через `⌘⌥V`, не отпуская `⌘⌥`, нажать V/C ещё раз и отпустить модификаторы: выбранная запись должна скопироваться, окно — закрыться. Отдельные одиночные нажатия с отпусканием каждый раз не должны закрывать окно. Прокрутить вниз, закрыть и снова открыть: видимые записи должны появиться сразу. Проверить действия карточки и их подсказки, `⌘1`–`⌘9`, просмотр по пробелу и `⌘Y`, избранное после повторного копирования и перезапуска, сохранение поиска между открытиями и явный сброс `⌘0`. Проверить Esc, фильтр приложения, календарь, временный экспорт, «Сохранить как…» и скрытие/временный показ на тестовом содержимом. Выполненные проверки и их ограничения перечислены в [docs/verification.md](docs/verification.md).
