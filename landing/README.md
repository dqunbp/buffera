# Buffera landing

Самостоятельный статический лендинг на русском. Исходники в `src/`, без внешних библиотек, шрифтов, аналитики или запросов к истории приложения. Объёмный фирменный знак нарисован CSS; пружина реагирует на указатель и нажатие, учитывает `prefers-reduced-motion` и останавливается вне экрана.

```sh
cd landing
npm run check
npm run build
npm run preview
```

Открыть http://127.0.0.1:4173. Сборка копирует четыре файла в `dist/`. Демо использует только вымышленные примеры, фильтруется и открывает просмотр с клавиатуры; буфер посетителя не читает и не меняет.

Тексты сверены с приложением и README на 21 октября 2026. Адрес репозитория задан владельцем: https://github.com/dqunbp/buffera. Кнопка скачивания ведёт в его раздел Releases, ссылка на исходники — в корень репозитория. Поиск по смыслу и встроенный чат требуют Apple Silicon и отдельных моделей. Ограничения маскировки и внешних AI-агентов указаны на странице. Экономия батареи относится к фоновой подготовке поиска по смыслу.

Хостинг Sites описан в `.openai/hosting.json`; сайт приватный по умолчанию. Для публикации используется отдельная копия только этого каталога, чтобы не отправлять исходники macOS-приложения и не создавать вложенный Git-репозиторий в рабочем дереве.
