# Buffera 1.2.0

## Русский

Сборка 8. macOS 14+, Apple Silicon.

### Что изменилось

- Обновлены настройки: компактная боковая навигация, раздел «ИИ» сразу после основных настроек и выбор языка в «Основных».
- Добавлены автозапуск при входе в macOS, управление значком в строке меню и информация о версии и сборке.
- Кнопка сообщения о проблеме открывает черновик GitHub Issue с версией Buffera, сборкой, версией macOS и архитектурой. Содержимое буфера и логи не добавляются.
- Лимит истории теперь можно уменьшить до 10, 100, 500, 1 000 или 5 000 записей. Избранное по-прежнему не входит в лимит.
- Сброс интерфейса можно выполнять сразу после закрытия или через заданное время: при следующем открытии очищены поиск и фильтры, закрыт режим избранного. Записи и избранное сохраняются.
- В разделе «История» появилась настройка «Сохранять временные записи» для содержимого, которое приложения помечают как временное или автоматически созданное, например при диктовке и автоматической вставке текста. По умолчанию она выключена. Для временных конфиденциальных записей также нужно отдельно включить сохранение конфиденциальных записей; они хранятся зашифрованными.
- Обновлены переводы и документация на всех восьми языках.

### Установка

В версиях 1.0.0 и 1.1.0 откройте Настройки → Обновления. Для ручной установки скачайте `Buffera-macOS-arm64.dmg`, закройте Buffera и замените приложение в папке установки. Версии 0.4.0 и старше обновляются вручную. Запускайте установленную копию, не приложение внутри DMG. История, настройки и модели хранятся отдельно; схема базы не меняется. После обновления перезапустите подключённые MCP-процессы.

## English

Build 8. macOS 14+, Apple Silicon.

### Changes

- Refreshed settings with compact sidebar navigation, AI directly after General, and language selection in General.
- Added launch at login, a menu bar icon toggle, and version and build information.
- The report issue button opens a GitHub Issue draft with the Buffera version, build, macOS version and architecture. Clipboard content and logs are not attached.
- History limits now include 10, 100, 500, 1,000 and 5,000 entries. Favorites remain excluded from the limit.
- Choose to reset the interface immediately after closing or after a delay: the next opening clears search and filters and leaves the favorites view. Entries and favorites are preserved.
- History settings now offer “Save temporary clips” for content that apps mark as temporary or automatically generated, such as during dictation and automatic text insertion. It is off by default. Saving temporary confidential entries also requires separately enabling confidential storage; those entries remain encrypted.
- Updated translations and documentation in all eight languages.

### Installation

In versions 1.0.0 and 1.1.0, open Settings → Updates. To install manually, download `Buffera-macOS-arm64.dmg`, quit Buffera and replace the app in its installation folder. Version 0.4.0 and older require manual installation. Launch the installed copy, not the app inside the DMG. History, settings and models are stored separately; the database schema is unchanged. Restart connected MCP processes after updating.

## Español

Compilación 8. macOS 14+, Apple Silicon.

### Cambios

- Ajustes renovados con navegación compacta en la barra lateral, IA justo después de General y selección de idioma en General.
- Se añadieron el inicio al iniciar sesión, la opción de mostrar el icono en la barra de menús y la información de versión y compilación.
- El botón para informar de un problema abre un borrador de GitHub Issue con la versión de Buffera, la compilación, la versión de macOS y la arquitectura. No se adjuntan el contenido del portapapeles ni los registros.

La opción está desactivada por defecto. Para guardar entradas temporales confidenciales también hay que activar por separado el almacenamiento confidencial; estas entradas siguen cifradas.

### Instalación

En las versiones 1.0.0 y 1.1.0, abre Ajustes → Actualizaciones. Para instalar manualmente, descarga `Buffera-macOS-arm64.dmg`, cierra Buffera y sustituye la app en su carpeta de instalación. La versión 0.4.0 y anteriores requieren instalación manual. Abre la copia instalada, no la del DMG. El historial, los ajustes y los modelos se guardan por separado; el esquema de la base de datos no cambia. Reinicia los procesos MCP conectados después de actualizar.

## 简体中文

构建号 8。macOS 14 及以上，Apple Silicon。

### 更新内容

- 重新设计设置界面：侧边栏导航更紧凑，AI 紧接在通用设置之后，语言选择移至通用设置。
- 新增登录时启动、菜单栏图标显示开关，以及版本和构建号信息。
- 问题反馈按钮可打开 GitHub Issue 草稿，包含 Buffera 版本、构建号、macOS 版本和架构，不附加剪贴板内容或日志。
- 历史记录数量上限新增 10、100、500、1,000 和 5,000 条选项。收藏仍不计入上限。
- 可选择关闭后立即或经过指定时间重置界面：下次打开时清空搜索和筛选，并退出收藏视图。记录和收藏不会删除。
- 历史记录设置新增保存临时记录的选项，可保存应用标记为临时或自动生成的内容，例如听写和自动插入的文本。此选项默认关闭。保存同时标记为机密的临时记录，还需单独开启机密记录存储；这些记录仍以加密形式保存。
- 更新了全部八种语言的翻译和文档。

### 安装

使用 1.0.0 或 1.1.0 版本时，请打开“设置 → 更新”。手动安装时，下载 `Buffera-macOS-arm64.dmg`，退出 Buffera，然后替换安装文件夹中的 App。0.4.0 及更早版本需要手动安装。请启动已安装的副本，而不是 DMG 内的 App。历史记录、设置和模型单独保存；数据库架构不变。更新后请重新启动已连接的 MCP 进程。

## 日本語

ビルド 8。macOS 14 以降、Apple Silicon。

### 変更点

- 設定画面を刷新しました。サイドバーのナビゲーションをコンパクトにまとめ、「一般」の次に「AI」を表示します。言語の選択は「一般」に移動しました。
- ログイン時の起動、メニューバーアイコンの表示切り替え、バージョンとビルド情報を追加しました。
- 問題を報告するボタンから、Bufferaのバージョン、ビルド、macOSのバージョン、アーキテクチャを含むGitHub Issueの下書きを開けます。クリップボードの内容やログは添付しません。
- 履歴の件数上限に10、100、500、1,000、5,000件を追加しました。お気に入りは引き続き上限に含まれません。
- 閉じた直後または指定時間後に画面の状態をリセットできます。次に開く際は検索とフィルタがクリアされ、お気に入り表示を終了します。履歴の項目とお気に入りは保持されます。
- 履歴の設定で、アプリが一時的または自動生成と指定した内容を保存できるようになりました。音声入力やテキストの自動挿入などが対象です。初期状態では無効です。機密にも指定された一時的な項目を保存するには、機密項目の保存も別途有効にする必要があり、それらは引き続き暗号化して保存されます。
- 全8言語の翻訳とドキュメントを更新しました。

### インストール

バージョン1.0.0または1.1.0では「設定 → アップデート」を開いてください。手動の場合は `Buffera-macOS-arm64.dmg` をダウンロードし、Bufferaを終了してインストール先のアプリを置き換えてください。0.4.0以前は手動インストールが必要です。DMG内ではなく、インストール済みのコピーを起動してください。履歴、設定、モデルは別に保存され、データベースのスキーマは変わりません。更新後は接続済みのMCPプロセスを再起動してください。
