# Buffera website

**English** · [Русский](../../landing/README.md) · [Documentation index](../README.md)

A standalone static landing page in eight languages: Russian, English, Spanish, German, French, Brazilian Portuguese, Simplified Chinese and Japanese. Its sources are in `landing/src/`, with no external UI libraries, fonts or requests to the app’s history. The three-dimensional brand mark is drawn in CSS; its spring motion responds to the pointer and clicks, respects `prefers-reduced-motion` and stops when offscreen. Unless stated otherwise, website source paths below are relative to `landing/`.

The landing page and all website documentation include Yandex Metrica counter `113828609`: session replay, click maps, link tracking, accurate bounce tracking, `ssr` and `ecommerce: "dataLayer"`, using the supplied snippet. The shared fragment is in `scripts/analytics.mjs` and is inserted by `renderPage` in `scripts/i18n.mjs`. Neutral routes that select a language automatically do not start the JavaScript counter before redirecting, so one visit is not counted twice; their English fallback pages still include the `noscript` pixel. Metrica applies to the public website and does not receive history from the Buffera app. Blocking the external script or failing to load it does not block the website interface.

Secret-handling behavior shared by all translations:

- Settings → History → Secrets in history defaults to “Do not save secrets”. The alternative is “Save secrets encrypted”. This setting affects new captures; previously saved secrets remain encrypted.
- Secrets are identified by source-app markers (`org.nspasteboard.ConcealedType` or `com.agilebits.onepassword`), not by password contents. Without a marker, a clip may be saved as ordinary content. The page therefore does not promise to detect every password automatically.
- When secret storage is enabled, secret payloads are encrypted with AES-256-GCM and the key is stored in macOS Keychain. If the key is unavailable, marked secrets are never saved in plaintext. Ordinary clips and secret metadata, such as the source app and date, remain unencrypted: the entire history is not encrypted.
- “Hide Content” also encrypts existing text or link content and removes it from search indexes, regardless of the setting for newly captured secrets. A secret can be temporarily revealed or copied in Buffera.
- Secret content is excluded from literal search, OCR, semantic search, the built-in assistant’s context and MCP. MCP never receives the key and can see only safe metadata for secret clips. The user enables MCP access to ordinary history; an external agent may send retrieved data to its own service.
- Local history and the built-in intelligent features do not require sending content to the cloud. This statement does not apply to connected external agents.

For behavior and storage details, see the [app guide](guide.md) and [architecture](architecture.md). These files are in the main repository; a separate copy of the landing sources in Sites does not include them.

## Website documentation

Documentation is available at `/<language>/docs/` for every supported language. The landing page’s header and footer link to “Documentation”; the MCP card links directly to the agent connection guide. Documentation retains the landing page’s palette, system font and raised materials. Wide screens show side navigation and an article table of contents; on narrow screens, navigation expands when pressed.

There are eight guides: `getting-started`, `history`, `search`, `assistant`, `privacy`, `shortcuts`, `agents` and `troubleshooting`. Each has its own static HTML, canonical URL, hreflang links and localized Open Graph / Twitter metadata using the existing brand cards. `/docs/` and `/docs/<article>/` select the browser language using the same mechanism as the website root, retaining the article, query and hash; without JavaScript, they show English text. As on the landing page, there is no explicit language switcher. Links from the landing page and between articles retain the chosen language version.

Copy lives in `src/locales/docs/<language>.json`. `scripts/docs.mjs` validates translation completeness and stable URLs and anchors, then renders typed blocks: paragraphs, steps, lists, notes, tables and code. Add new articles to every dictionary with matching `id` values and structure. Translations are escaped as text; dictionaries do not contain HTML. Search data is safely embedded in HTML. `src/docs.html`, `src/docs.css` and `src/docs.js` provide the template, styling and interface enhancements.

Search runs in the browser over section titles and full text, without network requests or external libraries. `/`, `⌘K` or `Ctrl+K` focuses search; Escape clears it. Results link to specific sections. Without JavaScript, text, links and expandable navigation remain available; search and copy controls are hidden. JSON is copied only when the user presses the button; if the browser denies access, the page explains that the text can be copied manually.

Sources for checking instructions are the README, the repository’s `docs/mcp.md`, `SecretHistorySettings.swift`, `MCPAccess.swift`, `AppearanceSettings.swift`, `HistoryPanel.swift`, `HistoryResetPreferences.swift` and app localization. The connection tab is named `MCP`; the pin button is to the right of the search field.
