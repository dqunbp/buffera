# Buffera landing

Самостоятельный статический лендинг на русском и английском. Исходники в `src/`, без внешних библиотек, шрифтов, аналитики или запросов к истории приложения. Объёмный фирменный знак нарисован CSS; пружина реагирует на указатель и нажатие, учитывает `prefers-reduced-motion` и останавливается вне экрана.

```sh
cd landing
npm run check
npm run build
npm run preview
```

Корневой адрес http://127.0.0.1:4173/ выбирает язык по предпочтениям браузера: первый поддерживаемый язык из `navigator.languages` (`ru` или `en`, включая региональные варианты), а если список недоступен — по `navigator.language`. Если поддерживаемого языка нет, используется английский. Перенаправление сохраняет query string и hash; отдельного переключателя на странице нет.

http://127.0.0.1:4173/ru/ и http://127.0.0.1:4173/en/ всегда открывают выбранный язык и не перенаправляют. Сборка создаёт готовый HTML для всех трёх адресов. Без JavaScript корень показывает полноценную английскую страницу, а явные языковые адреса сохраняют свой язык. Демо использует только вымышленные примеры, фильтруется и открывает просмотр с клавиатуры; буфер посетителя не читает и не меняет.

`src/index.html` — общий шаблон; весь переводимый текст, включая демо и доступные подписи, хранится в `src/locales/ru.json` и `en.json`. `scripts/i18n.mjs` проверяет полноту словарей, подстановки и стабильность идентификаторов демо. `npm run check` также проверяет готовый HTML, метаданные, безопасное встраивание JSON и выполняет корневой скрипт выбора языка в VM с разными настройками браузера. Для публикации нужен результат `npm run build`, а не необработанный шаблон.

Каждая языковая версия получает собственные canonical, hreflang, Open Graph и Twitter Card, включая PNG 1200×630 в `src/og/`. `x-default` указывает на корень, а его статическая английская версия использует canonical `/en/` и английские метаданные, в том числе для просмотра без JavaScript и внешних превью. Сборка публикует только PNG; SVG и `generate.mjs` сохраняют исходники графики. Для повторной генерации нужен `sharp`: `SHARP_MODULE=/path/to/node_modules/sharp node src/og/generate.mjs`. Адрес сайта для метаданных задан в `scripts/i18n.mjs`. Пока сайт приватный, внешние сервисы не смогут прочитать его OG-карточки.

Подпись `made by @dqunbp` ведёт в профиль GitHub; иконки — на https://t.me/crypto_and_pug и https://github.com/dqunbp. Ссылка на репозиторий приложения остаётся отдельной.

На первом экране — бейдж создания с GPT Astra в режиме Ultra. Он относится к разработке продукта; встроенные умные функции по-прежнему используют локальные модели. Чёрный знак OpenAI в `src/openai-mark.svg` взят из [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:OpenAI_logo_2025_(symbol).svg); логотип принадлежит OpenAI. Его пропорции и цвет сохранены, оформление находится на окружающем бейдже. [Руководство по знакам OpenAI](https://openai.com/brand/).

При наведении мыши бейдж наклоняется вслед за курсором, логотип и метка Ultra выступают над основанием, а по фону один раз проходит блик. Координаты считаются по неподвижной обёртке; обновление объединяется в один animation frame. Уход курсора, отмена указателя, скрытие вкладки или изменение настройки движения сбрасывают эффект. Сенсорный указатель и `prefers-reduced-motion` оставляют статичный бейдж; постоянного цикла анимации нет.

Тексты сверены с приложением и README на 21 октября 2026. Адрес репозитория задан владельцем: https://github.com/dqunbp/buffera. Кнопка скачивания ведёт прямо на `releases/latest/download/Buffera-macOS-arm64.dmg`; имя файла сохраняется между выпусками. Ссылка на исходники ведёт в корень репозитория. В карточке установки указаны Apple Silicon и инструкция первого запуска сборки без нотарификации Apple. Поиск по смыслу и встроенный чат требуют Apple Silicon и отдельных моделей. Ограничения маскировки и внешних AI-агентов указаны на странице. Экономия батареи относится к фоновой подготовке поиска по смыслу.

Хостинг Sites описан в `.openai/hosting.json`; сайт приватный по умолчанию. Для публикации используется отдельная копия только этого каталога, чтобы не отправлять исходники macOS-приложения и не создавать вложенный Git-репозиторий в рабочем дереве.

Демо повторяет панель приложения: поиск и булавка, история/избранное, боковые фильтры, действия карточек и крупные изображения. По умолчанию превью открывается в светлой теме. В фильтрах используются иконки Notes, Safari, Screenshot и Terminal из macOS, включённые в статическую сборку. Настройки (шестерёнка) переключают системную, светлую и тёмную тему только внутри демо. Поиск, тип, приложение, период, избранное, соседние записи, скрытие и просмотр работают на четырёх вымышленных записях; все они относятся к сегодняшнему дню. Копирование, Finder и сохранение показывают пояснение и не обращаются к буферу или файлам посетителя. SVG-скриншот кофейни — вымышленный пример.

Под поиском — галочка «Искать также по смыслу» и фирменная кнопка «Спросить», как в приложении. Галочка включает совпадения по подготовленным темам примеров (`keywords`); без неё поиск идёт по тексту и приложению-источнику. Модель в браузере не запускается. «Спросить» открывает подписанный готовый пример поиска адреса в истории буфера обмена. Ответ показывает карточку найденного скриншота, приложение-источник и время копирования; карточка открывает исходную запись. Диалог использует общее окно просмотра, Tab/Shift+Tab, Escape и возврат фокуса. Скрытое содержимое исключается из обоих режимов поиска.

Точечная текстура используется локально: с плавным затуханием за объёмным знаком, в тёмном блоке клавиш и внутри демо. В секции скачивания — отдельный редкий узор из фирменного знака (`brand-pattern.svg`), затухающий к тексту. Остальные текстовые разделы остаются на чистом фоне. Стеклянные элементы используют CSS backdrop-filter с плотной заливкой для браузеров без blur; уменьшение прозрачности и повышенный контраст отключают текстуру и размытие. В приложении панель поиска использует NSGlassEffectView на macOS 26+, а на macOS 14–15 — NSVisualEffectView.
