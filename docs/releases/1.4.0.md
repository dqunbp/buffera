# Buffera 1.4.0

## Русский

Сборка 10. macOS 14+, Apple Silicon.

### Что изменилось

- Подключайте совместимые модели из Foresight или кеша Hugging Face либо выбирайте файл вручную. Buffera проверяет файл и использует его по исходному пути без повторной загрузки.
- В меню Buffera можно приостановить запись истории или пропустить следующее копирование. Для обеих команд можно назначить глобальные сочетания клавиш.

### Установка

В Buffera 1.x откройте Настройки → Обновления. Для ручной установки скачайте `Buffera-macOS-arm64.dmg`, закройте Buffera и замените приложение в папке установки. Версии 0.4.0 и старше обновляются вручную. Запускайте установленную копию, не приложение внутри DMG. История, настройки и модели хранятся отдельно; схема базы не меняется. После обновления перезапустите подключённые MCP-процессы.

## English

Build 10. macOS 14+, Apple Silicon.

### Changes

- Use compatible models from Foresight or the Hugging Face cache, or select a file yourself. Buffera verifies the file and uses it in place without downloading it again.
- Pause history recording or skip the next copy from the Buffera menu. You can assign a global shortcut to each command.

### Installation

In Buffera 1.x, open Settings → Updates. To install manually, download `Buffera-macOS-arm64.dmg`, quit Buffera and replace the app in its installation folder. Version 0.4.0 and older require manual installation. Launch the installed copy, not the app inside the DMG. History, settings and models are stored separately; the database schema is unchanged. Restart connected MCP processes after updating.

## 简体中文

构建号 10。macOS 14 及以上，Apple Silicon。

### 更新内容

- 可使用 Foresight 或 Hugging Face 缓存中的兼容模型，也可手动选择文件。Buffera 会验证文件并直接从原位置使用，无需再次下载。
- 可在 Buffera 菜单中暂停记录剪贴板历史，或跳过下一次复制。两项操作均可设置全局快捷键。

## 日本語

ビルド 10。macOS 14 以降、Apple Silicon。

### 変更点

- Foresight や Hugging Face のキャッシュにある対応モデルを利用できます。ファイルを手動で選ぶこともできます。Buffera はファイルを検証し、再ダウンロードせずに元の場所から読み込みます。
- Buffera メニューから履歴の記録を一時停止したり、次のコピーを記録対象から外したりできます。各操作にグローバルショートカットを設定できます。

### インストール

Buffera 1.xでは「設定 → アップデート」を開いてください。手動の場合は `Buffera-macOS-arm64.dmg` をダウンロードし、Bufferaを終了してインストール先のアプリを置き換えてください。0.4.0以前は手動インストールが必要です。DMG内ではなく、インストール済みのコピーを起動してください。履歴、設定、モデルは別に保存され、データベースのスキーマは変わりません。更新後は接続済みのMCPプロセスを再起動してください。
