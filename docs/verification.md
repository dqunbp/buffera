# Проверка первой сборки, 16 октября 2026

- Release-сборка на Apple Silicon с установленными Command Line Tools: успешно.
- 9/9 исполняемых проверок SQLite: сохранение форматов после открытия базы, дедупликация, даты/тип/слова, буквальные SQL-символы, лимиты, каскадное удаление, пагинация, границы хеша, отказ от пустого payload.
- Smoke-проверка готового бинарника на отдельном системном pasteboard: несколько элементов и форматов, отсутствие собственного повторного захвата, внешний захват, TIFF → PNG, маркер конфиденциальности — успешно.
- Нативное окно осмотрено через UI automation. Проверены захват двух текстовых фрагментов, поиск, просмотр, стрелки, Enter с последующей вставкой выбранного текста, переходы ⌘⌥V/C внутри открытого окна, отображение произвольного периода, сохранение записей после перезапуска.
- До изменения поведения отпускания клавиш пользователь подтвердил глобальный вызов из другого приложения обычной клавиатурой. Диагностика в 21:22 (локальное время Mac) зафиксировала успешные регистрации (`status=0`), открытие панели, несколько нажатий V, два нажатия C и закрытие с возвратом фокуса.
- По следующему запросу пользователя автоподтверждение при отпускании модификаторов полностью удалено. Новая release-сборка установлена и запущена; в окне проверены поиск и оба направления ⌘⌥V/C: после отпускания сочетаний окно и запрос остаются, выбранная строка меняется. Теперь подтверждение выполняется только Enter или двойным щелчком.
- Пользователь подтвердил видимость нового значка Bufera в верхней системной строке меню. Pasta завершена перед проверкой.
- Экспорт через системный NSSavePanel/Finder и специфические форматы сторонних редакторов ещё не прошли полный ручной сценарий; преобразование изображения и сохранение бинарных форматов покрыты smoke-проверкой.

В истории приложения остались два явно тестовых текстовых фрагмента. OCR, поиск с опечатками, эмбеддинги и LLM не входят в эту версию.
