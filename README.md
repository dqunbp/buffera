# Bufera

Локальный менеджер истории буфера для macOS 13+, первая версия. Swift + AppKit, системная SQLite, без внешних зависимостей. OCR и LLM пока не включены.

## Сборка и запуск

Нужны Command Line Tools со Swift 5.9 или новее. Полный Xcode не обязателен.

```sh
zsh scripts/build-app.sh
open dist/Bufera.app
```

В среде, где запрещён вложенный `sandbox-exec`, передайте `--disable-sandbox` скрипту сборки. Это отключает только песочницу манифеста SwiftPM, а не защиту macOS приложения.

Получается локально подписанный ad-hoc пакет `dist/Bufera.app`. Для распространения понадобится Developer ID и notarization. Можно скопировать пакет в Applications. Для автозапуска добавьте его в «Системные настройки → Основные → Объекты входа».

Если Documents обслуживается файловым провайдером, тот может повторно добавить FinderInfo к собранному `.app`, нарушив строгую проверку подписи. Запускайте рабочую копию вне синхронизируемой папки, например из `~/Applications/Bufera.app`. Копирование без служебных атрибутов: `ditto --norsrc --noextattr dist/Bufera.app ~/Applications/Bufera.app`, затем `codesign --force --sign - ~/Applications/Bufera.app`.

Перед запуском закройте Pasta, если она занимает `⌘⌥V`. Bufera не вставляет автоматически и не запрашивает Accessibility для синтетического нажатия клавиш. macOS может отдельно запросить доступ к буферу обмена: для фоновой истории его нужно разрешить.

## Управление

| Действие | Клавиши |
| --- | --- |
| Открыть историю / следующий элемент | `⌘⌥V` |
| Предыдущий элемент, пока окно открыто | `⌘⌥C` |
| Перемещаться между строками списка или сетки | `↑` / `↓` |
| Перемещаться между соседними карточками вне поля поиска | `←` / `→` |
| Поместить выбранное в буфер и закрыть окно | `Enter` или двойной щелчок |
| Сразу выбрать одну из первых девяти записей текущего списка | `⌘1`–`⌘9` |
| Открыть просмотр выбранной записи | `Пробел` при фокусе в списке; `⌘Y` также из поиска |
| Добавить в избранное / убрать из него | `⌘D` |
| Скрыть содержимое / временно показать скрытое | `⇧⌘H` |
| Показать картинку в Finder | `⇧⌘R` |
| Сохранить картинку в выбранную папку | `⇧⌘S` |
| Перейти к поиску | `⌘F` |
| Переключить фокус между поиском и карточками | `Tab` |
| Показать / скрыть боковое меню фильтров | `⌘⌥S` |
| Открыть настройки внешнего вида | `⌘,` |
| Очистить запрос и фильтры, вернуться ко всей истории | `⌘0` |
| Отменить без изменения буфера | `Esc` |
| Удалить выбранную запись | `⌘⌫` |

Одиночное нажатие `⌘⌥V` активирует Bufera и открывает окно с фокусом в карточках. Окно остаётся открытым после отпускания всех клавиш. Повторные `⌘⌥V/C` всегда перебирают записи по одной. В сетке `↑/↓` переходят на строку вверх или вниз, `←/→` — к соседней карточке. Enter, кнопка «В буфер» в карточке или двойной щелчок фиксируют запись, помещают её содержимое в системный буфер и закрывают окно, возвращая фокус предыдущему приложению. Вставка выполняется пользователем в целевом приложении (обычно `⌘V`; Bufera не меняет пользовательские переназначения). Escape или переход в другое приложение закрывают окно без подтверждения; Escape также отменяет ещё не завершённое подтверждение.

Начните печатать при фокусе в списке, чтобы начать новый поиск. `⌘F` переводит фокус в существующий запрос для редактирования; пробелы в поле поиска остаются обычными пробелами. Запрос, фильтры и раздел «История»/«Избранное» сохраняются между закрытиями окна, пока Bufera работает. После перезапуска приложения они сбрасываются. Вернуться ко всей истории можно кнопкой сброса рядом с поиском или `⌘0`.

Через маленький значок планшета с зажимом справа в верхней системной строке меню тоже можно открыть историю. В его меню виден статус `⌘⌥V`; при конфликте доступно повторное подключение сочетания. Обычное копирование `⌘C` остаётся доступно в поле поиска.

Карточки расположены списком или сеткой; боковое меню с типами, периодом и приложениями можно скрыть кнопкой слева от поиска или `⌘⌥S`. Активные фильтры при этом сохраняются, а тип, дата и приложение доступны через значок фильтров рядом с поиском. В каждой карточке находятся содержимое, приложение, дата и действия: избранное, просмотр, копирование и доступные для её типа скрытие или экспорт. Кнопки видны постоянно, без наведения. Названия действий и сочетания клавиш видны в подсказках; контекстное меню содержит те же действия и удаление. Удержание `⌘` показывает номера первых девяти записей для быстрого выбора. Выбранная карточка выделена обводкой. Звезда обновляет карточку на месте; снятие звезды в избранном убирает только эту запись.

Просмотр по пробелу или кнопке в карточке открывается временно рядом со списком. В нём можно прочитать длинный текст, рассмотреть картинку, увидеть пути файлов или перечень других форматов. Пробел и Escape закрывают просмотр, Enter выбирает запись, стрелки возвращают к списку и меняют выбор. Полный текст не показывается при случайном наведении. Скрытую запись сначала нужно явно раскрыть кнопкой «Показать содержимое».

Шестерёнка справа от поиска, `⌘,` и пункт «Внешний вид…» в системном меню открывают настройки. Изменения применяются сразу и сохраняются после перезапуска. Доступны обычное окно и панели у левого или правого края экрана. Обычное окно можно перемещать за свободную область и растягивать за края; его положение и размер сохраняются отдельно от ширины боковой панели. Панель занимает доступную высоту экрана, допускает изменение ширины и выезжает из выбранного края при открытии. При включённом системном «Уменьшить движение» анимация отключена. Стандартные кнопки закрытия, сворачивания и разворачивания скрыты; окно закрывается через Escape или выбор записи.

Можно выбрать 1–4 колонки и плотность в 3–12 видимых строк. Одна колонка даёт список, несколько — сетку. Фактическая раскладка учитывает доступное место: минимальный размер карточки — 230 × 96 точек, поэтому в узком окне колонок может быть меньше, а при высокой плотности нужна прокрутка. Размер окна ограничивается видимой областью экрана; при отключении монитора обычное окно возвращается на доступный экран. Фон использует системную полупрозрачность с размытием, а текст остаётся непрозрачным. Вид эффекта зависит от темы и системной настройки «Уменьшить прозрачность».

## Что входит

- Захват новых копирований каждые 400 мс, пока приложение запущено.
- Сохранение доступных бинарных представлений каждого элемента, включая текст, RTF, PNG/TIFF, ссылки, группы файлов и пользовательские форматы.
- Повторное копирование одинакового содержимого поднимает существующую запись наверх; дата и приложение заменяются данными последнего копирования. Маска и отметка избранного сохраняются.
- Поиск по всем словам запроса без учёта регистра, по фрагментам текста, имени файла и названию приложения. Символы `%` и `_` ищутся буквально. Опечатки и смысловой поиск пока не поддерживаются.
- Боковое меню с типами, периодом и приложениями. Компактное меню фильтров рядом с поиском доступно и при скрытом сайдбаре; «Сбросить фильтры» очищает их вместе, сохраняя поисковый запрос.
- В календарном поповере доступны «Всё время», «Сегодня», «Вчера», «7 дней», «30 дней» и два календаря для границ периода. Последний выбранный день включается целиком; обратный порядок дат исправляется автоматически. Периоды в 7 и 30 дней включают сегодня, даты используют локальный часовой пояс macOS.
- Фильтр приложения выбирает точное имя источника последнего копирования из имеющейся истории и сочетается с текстом, типом и датой. Имена отсортированы без учёта регистра; сама Bufera не предлагается в списке источников, но её записи остаются в общей истории. Источник определяется по метаданным буфера, когда они доступны; иначе используется активное приложение.
- Звезда в карточке добавляет запись в избранное. Раздел «Избранное» сочетается с поиском и всеми фильтрами; записи сохраняются после перезапуска и защищены от автоматической очистки истории.
- Страницы по 150 записей, подгружаемые при прокрутке. Полные двоичные данные читаются отдельно от списка.
- PNG/TIFF можно экспортировать в PNG: «Сохранить как…» создаёт постоянный файл в выбранном месте, «Показать в Finder» — временный файл с автоматической очисткой.
- Помеченные конфиденциальные записи сохраняются под точками; обычный текст или ссылку можно скрыть вручную. «Показать» временно раскрывает содержимое выбранной скрытой записи.
- Пауза записи, удаление отдельных записей, лимиты количества и объёма в меню.

## Данные и ограничения первой версии

История находится в `~/Library/Application Support/Bufera/`: `history.sqlite` и служебные файлы SQLite. Текущая версия схемы — 3. При открытии базы версии 0/1/2 в одной транзакции добавляются недостающие признаки скрытой записи и избранного; существующие идентификаторы, записи и исходное содержимое сохраняются. Неизвестная более новая версия не понижается.

«Показать в Finder» создаёт PNG в системной временной папке `$TMPDIR/local.bufera.app/ImageExports/`. Повторный показ той же картинки обновляет временный файл и срок хранения. Файлы старше 24 часов с последнего показа удаляются при запуске, раз в час, пока Bufera работает, и при новом экспорте. При превышении 256 МиБ удаляются самые старые файлы; текущий экспорт сохраняется. macOS также может очистить временную папку.

Для постоянного файла используйте «Сохранить как…» или скопируйте временную картинку в свою папку: независимую копию очистка Bufera не затронет. Исходная картинка остаётся в истории в пределах её лимитов. Старую папку `~/Library/Application Support/Bufera/Exports/`, созданную прежней версией, Bufera автоматически не удаляет.

По умолчанию сохраняется до 50 000 обычных записей и 5 ГБ их сериализованного содержимого. Оба ограничения применяются в транзакции после нового копирования; удаляется старейшая часть обычной истории. Избранные записи не расходуют эти лимиты и не удаляются автоматически, поэтому суммарный объём истории может превышать установленный лимит. Снятие звезды само по себе ничего не удаляет: запись снова участвует в очистке при следующем копировании. Явное удаление записи работает и для избранного. Размер самого файла SQLite может оставаться больше после удаления записей: свободные страницы переиспользуются. Экспортированные картинки в лимит истории не входят: временные файлы имеют отдельные ограничения, постоянные сохраняются до удаления пользователем.

Одна запись ограничена 64 МБ исходных представлений, индексируемый текст — 200 000 символов. Содержимое при этом сохраняется полностью в пределах 64 МБ. О пропусках или ошибках можно узнать через «Последняя ошибка…» в меню. Буфер, существовавший до запуска, не импортируется автоматически.

По выбранному режиму данные с маркерами `org.nspasteboard.ConcealedType` и старым маркером 1Password `com.agilebits.onepassword` сохраняются как скрытые записи. Список показывает точки и значок замка. Секрет не попадает в заголовок, текстовый индекс или всплывающую подсказку; запись можно найти по безопасному названию «Скрытая запись», приложению и дате. «Показать» раскрывает до 4000 символов выбранной записи только до смены выбора, обновления списка или закрытия окна. Эта кнопка не снимает сохранённую маску.

Если приложение не пометило пароль, он сохраняется как обычный текст. Такую текстовую запись или ссылку можно выбрать и нажать «Скрыть»: содержимое исчезнет из списка и текстового поиска, но останется доступным для вставки. Повторное копирование того же полного payload не снимает маску. Автоматическое определение любых паролей по самому тексту не выполняется.

Маскировка управляет показом и поиском: оригинальный payload сохраняется полностью и не шифруется отдельно от диска. Записи с `TransientType` или `AutoGeneratedType` пропускаются, если у них нет конфиденциального маркера; при сочетании маркеров сохраняется скрытая запись.

Файлы сохраняются как ссылки на оригиналы, а не резервные копии. Удалённый или перемещённый оригинал не восстанавливается. Отложенные file promises и данные, которые приложение-источник не отдаёт, пока не материализуются в самостоятельные файлы. В этом случае запись может быть пропущена с сообщением. Не все специфические форматы приложений проверены.

## Проверка

```sh
CLANG_MODULE_CACHE_PATH="$PWD/.build/ModuleCache" \
SWIFTPM_MODULECACHE_OVERRIDE="$PWD/.build/ModuleCache" \
swift run --cache-path "$PWD/.build/cache" BuferaChecks
.build/debug/Bufera --smoke-test
```

Smoke-проверка использует отдельный именованный системный буфер и не меняет основной буфер пользователя. Проверки хранилища работают с временной базой; исполняемый набор не требует XCTest или полного Xcode.

Ручная проверка: скопировать текст/картинку/несколько файлов, вызвать окно, отпустить клавиши (окно должно остаться), перебрать V/C и стрелками, нажать Enter (окно должно закрыться), затем вставить в исходное приложение. Проверить действия карточки и их подсказки, `⌘1`–`⌘9`, просмотр по пробелу и `⌘Y`, избранное после повторного копирования и перезапуска, сохранение поиска между открытиями и явный сброс `⌘0`. Проверить Esc, фильтр приложения, календарь, временный экспорт, «Сохранить как…» и скрытие/временный показ на тестовом содержимом. Выполненные проверки и их ограничения перечислены в [docs/verification.md](docs/verification.md).
