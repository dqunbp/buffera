# Buffera 1.1.0

## Русский

Сборка 7. macOS 14+, Apple Silicon.

### Что изменилось

- История подготавливается в фоне после закрытия и изменений записей: повторное открытие использует готовые карточки и сохраняет выбор.
- Закрытие контекстного меню больше не считается щелчком вне истории; отмена меню сохраняет панель открытой.
- В настройках внешнего вида появились пояснения с иллюстрациями для расположения окна, колонок и видимых строк.
- Первоначальная настройка сокращена до пяти шагов; внешний вид истории настраивается в настройках.
- В шапку настроек добавлена кнопка перехода на GitHub. Обновлены переводы и документация.

### Установка

В версии 1.0.0 откройте Настройки → Обновления и выберите обновление. Для ручной установки скачайте `Buffera-macOS-arm64.dmg`, закройте Buffera и замените приложение в папке установки. Версии 0.4.0 и старше обновляются вручную. Запускайте установленную копию, не приложение внутри DMG. История, настройки и модели хранятся отдельно; схема базы не меняется. После обновления перезапустите подключённые MCP-процессы.

## English

Build 7. macOS 14+, Apple Silicon.

### Changes

- History is prepared in the background after closing and record changes, so reopening uses ready cards and preserves selection.
- Closing a context menu no longer counts as an outside click; cancelling the menu keeps history open.
- Appearance settings now include illustrated explanations for window placement, columns and visible rows.
- Initial setup has five steps; history appearance is configured in Settings.
- A GitHub link button has been added to the settings header. Translations and documentation have been updated.

### Installation

From version 1.0.0, open Settings → Updates and choose the update. To install manually, download `Buffera-macOS-arm64.dmg`, quit Buffera and replace the app in its installation folder. Version 0.4.0 and older require manual installation. Launch the installed copy, not the app inside the DMG. History, settings and models are stored separately; the database schema is unchanged. Restart connected MCP processes after updating.

## Español

Compilación 7. macOS 14+, Apple Silicon.

### Cambios

- El historial se prepara en segundo plano al cerrarlo y tras cambios en los registros; al volver a abrirlo, las tarjetas están listas y se conserva la selección.
- Cerrar o cancelar el menú contextual ya no cierra el panel del historial.

La versión 0.4.0 y anteriores requieren instalación manual. Abre la copia instalada, no la del DMG. El historial, los ajustes y los modelos se guardan por separado; el esquema de la base de datos no cambia. Reinicia los procesos MCP conectados después de actualizar.

## 简体中文

构建号 7。macOS 14 及以上，Apple Silicon。

### 更新内容

- 关闭历史记录面板或修改记录后，会在后台准备卡片。再次打开时可立即使用已准备好的卡片，并保留选择。
- 关闭或取消上下文菜单不再导致历史记录面板关闭。
- 外观设置新增图文说明，介绍窗口位置、列数和可见行数。
- 首次设置简化为五个步骤；历史记录外观可在设置中调整。
- 设置页顶部新增 GitHub 按钮，并更新了翻译和文档。

### 安装

使用 1.0.0 版本时，请打开“设置 → 更新”。手动安装时，下载 `Buffera-macOS-arm64.dmg`，退出 Buffera，然后替换安装文件夹中的 App。0.4.0 及更早版本需要手动安装。请启动已安装的副本，而不是 DMG 内的 App。历史记录、设置和模型单独保存；数据库架构不变。更新后请重新启动已连接的 MCP 进程。

## 日本語

ビルド 7。macOS 14 以降、Apple Silicon。

### 変更点

- 履歴を閉じた後や項目の変更後に、バックグラウンドでカードを準備します。再度開く際は準備済みのカードを表示し、選択を保持します。
- コンテキストメニューを閉じたりキャンセルしたりしても、履歴パネルが閉じなくなりました。
- 外観設定に、ウインドウ位置、列数、表示行数の図解付き説明を追加しました。
- 初期設定を5ステップに簡略化しました。履歴の外観は設定から変更できます。
- 設定画面の上部にGitHubボタンを追加し、翻訳とドキュメントを更新しました。

### インストール

バージョン1.0.0では「設定 → アップデート」を開いてください。手動の場合は `Buffera-macOS-arm64.dmg` をダウンロードし、Bufferaを終了してインストール先のアプリを置き換えてください。0.4.0以前は手動インストールが必要です。DMG内ではなく、インストール済みのコピーを起動してください。履歴、設定、モデルは別に保存され、データベースのスキーマは変わりません。更新後は接続済みのMCPプロセスを再起動してください。
