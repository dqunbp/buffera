# Buffera 1.3.0

## Русский

Сборка 9. macOS 14+, Apple Silicon.

### Что изменилось

- Замок каждой записи работает независимо: скрытие или раскрытие одной карточки не переключает соседние.
- Открытие замка возвращает запись в обычную историю. Она остаётся открытой после закрытия окна, переключения приложений и перезапуска Buffera, пока вы явно не скроете её снова. После раскрытия запись снова доступна поиску, встроенному помощнику и разрешённому чтению MCP.
- При скрытии записи история больше не исчезает перед обновлением результатов. Устранены лишние маски при перерисовке карточек.
- Значок глаза заменён замком, а верхняя панель истории поднята на 5 пунктов.
- Обновлены подсказки, переводы и документация для нового поведения замка.

### Установка

В Buffera 1.x откройте Настройки → Обновления. Для ручной установки скачайте `Buffera-macOS-arm64.dmg`, закройте Buffera и замените приложение в папке установки. Версии 0.4.0 и старше обновляются вручную. Запускайте установленную копию, не приложение внутри DMG. История, настройки и модели хранятся отдельно; схема базы не меняется. После обновления перезапустите подключённые MCP-процессы.

## English

Build 9. macOS 14+, Apple Silicon.

### Changes

- Each item's lock works independently: hiding or showing one card does not change neighboring cards.
- Opening a lock returns the item to ordinary history. It stays visible after closing the window, switching apps, and restarting Buffera until you explicitly hide it again. Once shown, the item is available to search, the built-in assistant, and permitted MCP reading again.
- Hiding an item no longer empties the history before refreshed results arrive. Removed duplicate masks during card redraws.
- Replaced the eye icon with a lock and moved the history toolbar up by 5 points.
- Updated hints, translations, and documentation for the lock's new behavior.

### Installation

In Buffera 1.x, open Settings → Updates. To install manually, download `Buffera-macOS-arm64.dmg`, quit Buffera and replace the app in its installation folder. Version 0.4.0 and older require manual installation. Launch the installed copy, not the app inside the DMG. History, settings and models are stored separately; the database schema is unchanged. Restart connected MCP processes after updating.

## Español

Compilación 9. macOS 14+, Apple Silicon.

### Cambios

- El candado de cada entrada funciona de forma independiente: ocultar o mostrar una tarjeta no cambia las tarjetas vecinas.
- Abrir el candado devuelve la entrada al historial normal. Permanece visible al cerrar la ventana, cambiar de app y reiniciar Buffera hasta que la ocultes de nuevo de forma explícita. Una vez mostrada, vuelve a estar disponible para la búsqueda, el asistente integrado y la lectura autorizada mediante MCP.
- Al ocultar una entrada, el historial ya no desaparece mientras llegan los resultados actualizados. Se eliminaron las máscaras duplicadas al redibujar las tarjetas.
- El icono del ojo se sustituyó por un candado y la barra superior del historial se desplazó 5 puntos hacia arriba.
- Se actualizaron las indicaciones, las traducciones y la documentación para el nuevo comportamiento del candado.

### Instalación

En Buffera 1.x, abre Ajustes → Actualizaciones. Para instalar manualmente, descarga `Buffera-macOS-arm64.dmg`, cierra Buffera y sustituye la app en su carpeta de instalación. La versión 0.4.0 y anteriores requieren instalación manual. Abre la copia instalada, no la del DMG. El historial, los ajustes y los modelos se guardan por separado; el esquema de la base de datos no cambia. Reinicia los procesos MCP conectados después de actualizar.

## Deutsch

- Das Schloss jedes Eintrags funktioniert unabhängig: Das Verbergen oder Anzeigen einer Karte verändert keine benachbarten Karten.

- Hinweise, Übersetzungen und Dokumentation wurden an das neue Verhalten des Schlosses angepasst.

### Installation

Öffne in Buffera 1.x Einstellungen → Updates. Zur manuellen Installation lade `Buffera-macOS-arm64.dmg` herunter, beende Buffera und ersetze die App im Installationsordner. Version 0.4.0 und ältere erfordern eine manuelle Installation. Starte die installierte Kopie, nicht die App in der DMG. Verlauf, Einstellungen und Modelle werden separat gespeichert; das Datenbankschema bleibt unverändert. Starte verbundene MCP-Prozesse nach dem Update neu.

## 简体中文

构建号 9。macOS 14 及以上，Apple Silicon。

### 更新内容

- 每条记录的锁独立工作：隐藏或显示一张卡片不会改变相邻卡片。
- 打开锁会将该记录恢复为普通历史记录。关闭窗口、切换应用或重启 Buffera 后，它仍然可见，直到你再次明确将其隐藏。恢复显示后，该记录可重新用于搜索、内置助手和已获授权的 MCP 读取。
- 隐藏记录时，历史列表不再在等待更新结果期间消失。修复了卡片重绘时出现重复遮罩的问题。
- 将眼睛图标替换为锁图标，并将历史记录顶部工具栏上移 5 点。
- 更新了提示、翻译和文档，以说明锁的新行为。

### 安装

使用 Buffera 1.x 时，请打开“设置 → 更新”。手动安装时，下载 `Buffera-macOS-arm64.dmg`，退出 Buffera，然后替换安装文件夹中的 App。0.4.0 及更早版本需要手动安装。请启动已安装的副本，而不是 DMG 内的 App。历史记录、设置和模型单独保存；数据库架构不变。更新后请重新启动已连接的 MCP 进程。

## 日本語

ビルド 9。macOS 14 以降、Apple Silicon。

### 変更点

- 各項目のロックが独立して動作します。1枚のカードを非表示または表示にしても、隣のカードは変わりません。
- ロックを開くと、その項目は通常の履歴に戻ります。ウィンドウを閉じたり、アプリを切り替えたり、Bufferaを再起動したりしても、明示的に再び非表示にするまで表示されたままです。表示に戻した項目は、検索、内蔵アシスタント、許可されたMCPの読み取りで再び利用できます。
- 項目を非表示にするとき、更新結果を待つ間に履歴が消えなくなりました。カードの再描画時にマスクが重複する問題も修正しました。
- 目のアイコンをロックに変更し、履歴の上部ツールバーを5ポイント上に移動しました。
- ロックの新しい動作に合わせて、ヒント、翻訳、ドキュメントを更新しました。

### インストール

Buffera 1.xでは「設定 → アップデート」を開いてください。手動の場合は `Buffera-macOS-arm64.dmg` をダウンロードし、Bufferaを終了してインストール先のアプリを置き換えてください。0.4.0以前は手動インストールが必要です。DMG内ではなく、インストール済みのコピーを起動してください。履歴、設定、モデルは別に保存され、データベースのスキーマは変わりません。更新後は接続済みのMCPプロセスを再起動してください。
