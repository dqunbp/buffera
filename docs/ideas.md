# Идеи развития Buffera

Обсуждение и согласованный порядок работ от 19 октября 2026 года. Этапы выполняются по отдельности, с проверкой работающего приложения после каждого.

## Выбранные направления

### Скопировать иначе

Действия над записью: текст без оформления, очистка переносов, удаление повторяющихся строк, форматирование JSON, удаление выбранных трекинговых параметров ссылки и копирование распознанного текста картинки. Через необязательную LLM — перевод, сокращение и изменение тона. Базовые действия выбираются в подменю по правому клику и сразу копируют результат; неподходящие варианты скрыты, исходная запись сохраняется.

### Что я копировал рядом

Показать копирования до и после найденной записи, чтобы восстановить ход работы: команда, ошибка, ссылка на документацию и исправленный вариант. Первый вариант работает по уже сохранённой дате последнего копирования, без MCP, эмбеддингов, LLM и миграции базы. Повторный захват одинакового содержимого обновляет дату и источник существующей записи. Отдельные события нужны только для будущего полного журнала повторов; события, которые ранее не сохранялись, восстановить достоверно нельзя.

## Общая основа следующих этапов

- Локальный MCP через stdio для доступа внешних агентов к Buffera.
- Текстовые эмбеддинги и гибридный поиск по истории.
- Встроенный локальный чат с LLM, которая ищет в истории и отвечает по найденным записям.

Обычный интерфейс, встроенный чат и внешний агент используют общие операции поиска и чтения истории. MCP предоставляет эти операции внешним агентам через локальный исполняемый файл и stdio; разговорная модель для него не обязательна. Эмбеддинги и чат включаются независимо. Конкретные модели, формат загрузок и среда выполнения остаются кандидатами до проверки на целевом Mac.

### Целевая платформа встроенных моделей

Согласовано: минимальная система Buffera — macOS 14. Для встроенных моделей на первом этапе ориентируемся на Apple Silicon (M1 и новее); поддержка моделей на Intel отложена.

MLX Swift остаётся основным кандидатом для запуска моделей. Выбор Apple Silicon и macOS 14 сам по себе не означает, что модель или движок уже подключены.

Этапы 1–3 реализованы, проверены и установлены для просмотра. Результаты проверок фиксируются в [verification.md](verification.md).

## Отложено до отдельного обсуждения

### Корзина контекста и результаты агентов

Собрать несколько текстов, ссылок и картинок в набор с пояснением; передать агенту через MCP или скопировать одним блоком. Ответ агента появляется отдельной карточкой со связью с исходными материалами.

### Очередь для переноса данных

Выбрать записи, задать порядок и отдельным сочетанием последовательно помещать следующую запись в буфер. Продвижение по очереди — явное действие пользователя.

### Шаблоны с заполняемыми полями

Повторно используемые промпты, письма и описания задач с несколькими полями. В поля можно подставлять выбранные записи истории.

### Вернуться к источнику

Открыть исходную страницу или документ скопированного фрагмента. Точный источник требует доступных метаданных или отдельной интеграции; одного имени приложения недостаточно.

## Идеи из исходного обсуждения

Сохранены для возврата к ним; реализация не согласована:

- «Найти похожее» у записи.
- Умные автоматически пополняемые коллекции.
- Сравнение похожих версий текста.
- Сборка заметки, письма или описания задачи из выбранных записей.
- Поиск изображений по смыслу с помощью мультимодальных эмбеддингов.
