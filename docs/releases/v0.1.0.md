# Buffera 0.1.0

Clipboard history for Mac with search by meaning and a local AI assistant.

- Saves text, links, images and file references; favorites, filters and nearby history.
- Recognizes text in images and cleans up copied text and links.
- Optional semantic search and chat run locally. Models download separately in Settings.
- Russian and English interface; MCP access for external agents is opt-in.

## Download and install

Download **Buffera-macOS-arm64.dmg**, open it and drag Buffera into Applications.
Requires **Apple Silicon (M1 or later) and macOS 14+**. Intel is not supported by this download.
Press **⌘⌥V** to open history.

This first release is ad-hoc signed, without Developer ID or Apple notarization. If macOS blocks it, first attempt to launch Buffera, then open **System Settings → Privacy & Security → Open Anyway**. [Apple’s instructions](https://support.apple.com/en-us/102445).

`SHA256SUMS.txt` contains the checksum of the DMG. Model weights are not bundled.

## По-русски

Первый выпуск Buffera: история буфера обмена, избранное, фильтры, текст из картинок, поиск по смыслу и умный помощник. Умные функции работают локально; модели скачиваются отдельно в настройках.

Скачай **Buffera-macOS-arm64.dmg** и перетащи приложение в Программы. Нужны **Apple Silicon и macOS 14+**. История открывается по **⌘⌥V**.

Выпуск пока без сертификата Developer ID и нотарификации Apple. Если macOS блокирует запуск, после первой попытки разреши запуск Buffera в **Системных настройках → Конфиденциальность и безопасность**. [Инструкция Apple](https://support.apple.com/ru-ru/102445).
