## Одноколоночное окно и сохранение геометрии

- Release-сборка и строгая проверка подписи установленной копии проходят. Smoke-проверка именованного pasteboard проходит; пользовательский буфер для неё не используется.
- В приложении проверены список без правой панели, поиск тестовых записей и миниатюра изображения. При выборе картинки появляются обе кнопки экспорта.
- Через UI automation окно уменьшено с 671 × 673 до 481 × 403 pt. Поиск, список, подсказки, кнопки изображения и произвольный период помещаются; список прокручивается.
- Размеры 671 × 673 и затем 481 × 403 восстановлены после перезапусков. Native defaults содержат `NSWindow Frame BuferaHistory` с рамкой окна; повторное открытие больше не центрирует её. После последнего перезапуска проверен переход ⌘⌥V к следующей тестовой записи.

- Для фона используется системный `.popover / .behindWindow`. Захват отдельного окна не показывает композицию с рабочим столом; степень визуального размытия проверяется на экране пользователя.

## Исправление мигания при нажатии звезды

- После сохранения звезды обновляется существующая кнопка карточки и её локальная модель. Полная очистка списка и повторный запрос первой страницы удалены; действия карточек больше не вызывают принудительную прокрутку к строке.
- При снятии звезды в «Избранном» удаляется только соответствующая строка, сохраняется соседний выбор. Следующая страница не запрашивается, пока незавершённые операции избранного могут изменить её смещение.
- В установленной release-сборке список прокручен до конца. После добавления тестовой записи изменились только выделение и подпись существующей кнопки звезды; карточки сохранили AX-идентификаторы, прокрутка осталась в конце.
- Во вкладке «Избранное» снята звезда с первой из двух тестовых записей: счётчик стал 1, соседняя карточка сохранила AX-идентификаторы и получила выбор. Снятие последней звезды корректно показало пустой список. Обе тестовые отметки убраны, все 10 записей остались в истории.
- Release-сборка, строгая проверка подписи установленного приложения и `git diff --check` проходят. Исправление пока не закоммичено.
