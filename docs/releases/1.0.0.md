# Buffera 1.0.0 — публичный пилот

Первый основной выпуск Buffera для публичного пилота. Для Mac с Apple Silicon и macOS 14 или новее. Сборка 6.

## Что нового

- Восемь языков интерфейса, сайта и справки: русский, английский, испанский, немецкий, французский, португальский (Бразилия), китайский (упрощённый) и японский. Системный режим выбирает первый поддерживаемый язык из настроек macOS.
- Установка следующих обновлений из «Настройки → Обновления → Обновить…». Загрузка, проверка подписанного обновления, замена приложения и перезапуск выполняются через Sparkle после подтверждения пользователем. Фоновые проверки по-прежнему работают через GitHub; автоматическая установка выключена.
- Приложение и вложенные компоненты подписаны Developer ID с защищённой временной меткой и Hardened Runtime. Установочный DMG прошёл нотарификацию Apple; билет проверки прикреплён к файлу.
- Устранено мерцание истории при открытии и смене поиска: предыдущие карточки остаются видимыми до готовности нового результата, а открытие пустого окна откладывается до подготовки карточек.
- Запросы короче трёх символов после удаления внешних пробелов используют обычный поиск без запуска модели. Статус поиска различает поиск совпадений и поиск по смыслу.
- Настройки истории сгруппированы по хранению, скрытым записям и сбросу поиска. Выбор имени текстового файла перенесён в меню «Скопировать иначе». Исправлены размещение переводов и отображение индикатора обновлений в светлой и тёмной теме.

## Установка и обновление

Скачайте `Buffera-macOS-arm64.dmg`, завершите Buffera и перетащите приложение в «Программы», подтвердив замену. Если приложение установлено в другой папке, замените его там. Запускайте установленную копию, а не приложение внутри DMG.

С версии 0.4.0 и более ранних требуется ручная установка: в них ещё нет установщика Sparkle. История, настройки и скачанные модели хранятся отдельно. Формат истории остаётся схемой 10, как в 0.4.0. После обновления перезапустите подключённые MCP-процессы из нового пакета приложения.

При первом запуске подтвердите открытие загруженного приложения, если macOS попросит. Связка ключей может повторно запросить доступ к существующим скрытым записям после смены подписи.

Веса локальных моделей скачиваются отдельно в настройках. Подписанный канал обновлений находится в `appcast.xml`; контрольные суммы DMG и канала — в `SHA256SUMS.txt`.

## English

Buffera 1.0.0 is the first major release for the public pilot. Requires Apple Silicon and macOS 14+. Build 6.

- Added Spanish, German, French, Brazilian Portuguese, Simplified Chinese and Japanese alongside Russian and English across the app, website and help pages.
- Added user-initiated installation of future updates through Sparkle in Settings → Updates. GitHub remains the background update checker; unattended installation is disabled.
- Signed the app and its bundled components with Developer ID, secure timestamps and Hardened Runtime. The installation DMG is notarized by Apple, with its notarization ticket attached.
- Fixed history flicker during opening and search changes, with previous cards retained until replacement results are ready.
- Queries shorter than three characters after trimming whitespace use literal search without invoking the model. Search status now distinguishes literal and semantic queries.
- Reorganized history settings, moved text-file naming into the “Copy as” menu, and improved translated layouts and update indicators in light and dark appearances.

Download the DMG, quit Buffera and replace the installed app. Version 0.4.0 and earlier require this manual upgrade to gain the installer. History, settings and downloaded models are stored separately; the history format remains schema 10. Restart connected MCP processes after updating.

On first launch, confirm opening the downloaded app if macOS asks. Keychain may request access again after the signing change. Model weights are downloaded separately. The release includes the signed `appcast.xml` and `SHA256SUMS.txt` for both downloadable artifacts.
